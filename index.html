設定・同期・バックアップ

GitHub Gist 同期

  1. GitHub → Settings → Developer settings → Personal access tokens で新規トークンを作成（Classicなら gist のみにチェック）。
  2. 上の欄にトークンを貼り、「保存して同期」。Gist ID が空なら自動で非公開Gistが作られ、ここに表示されます。
  3. スマホなど別端末では、同じトークンと表示された Gist ID を入力すれば同じメモを共有できます（トークンは端末の localStorage にのみ保存されます）。
